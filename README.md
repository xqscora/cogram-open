## One-line pitch

Cogram as **AI software**: session-scoped Frozen Memory + MFA Pacing Gauge for study focus — web demo, not a robotics stack.

---

## Run locally

```bash
cd cogram_open
python -m http.server 8766
```

Open http://localhost:8766

Record demo: `python _record_demo.py` (needs server on 8766)

| Layer | Scope |
